# gha-e2e-secret-migration-r-94947e1942e1

Lab fixture for an end-to-end test of `buildkite-gha migrate-secrets`
(buildkite/buildkite-gha PR 247). Repository secrets hold synthetic canary values only.

- `.github/workflows/migrate-*.yml`: generated by `migrate-secrets prepare`, reviewed, committed unchanged.
- `.buildkite/verify.sh`: Buildkite step that compares migrated values by SHA-256 without printing them.
